# Teller

A bank support agent that reads policy documents, verifies the customer and makes the change in the bank's database.

It opens in the offline demo, where a short script plays the language model and the search, checks and bank tools are real. To use a real model, open **Model** in the top bar and paste your own Gemini, Anthropic or OpenAI key. The key is used for that case only and is never saved.

Code, tests and evaluation: https://github.com/umangbagadi03/teller
